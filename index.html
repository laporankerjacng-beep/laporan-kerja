🟢 Google Sheet: Siap Dihubungkan
Masukkan URL Web App hasil deploy Apps Script dari Google Spreadsheet Anda.
📋 Panduan Hubungkan Google Spreadsheet:
  1. Buka Google Spreadsheet baru di browser Anda.
  2. Klik menu Extensions > Apps Script, salin isi file google-apps-script/Code.gs lalu Paste di sana.
  3. Klik Deploy > New deployment (Pilih Web App, Access: Anyone), lalu tempel URL .../exec di kolom atas.
